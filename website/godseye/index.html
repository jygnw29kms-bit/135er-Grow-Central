Live Layers

Eine Welt. Viele Datenebenen.

Der Windows-Client kapselt die Web-Anwendung als Desktop-App und hält die eigentlichen Datenquellen modular.

01 // ADS-B

Flugverkehr

Zivile und öffentlich sichtbare militärische Flugbewegungen aus unterstützten ADS-B-Quellen.

02 // ORBIT

Satelliten

Satellitenpositionen und Orbitaldarstellung auf Basis öffentlich verfügbarer Bahndaten.

03 // AIS

Schiffsverkehr

Optionale AIS-Live-Daten für maritime Bewegungen und Objektverfolgung.

04 // USGS

Erdbeben

Aktuelle seismische Ereignisse und geographische Darstellung auf dem 3D-Globus.

05 // CCTV

Öffentliche Kameras

Unterstützte, öffentlich bereitgestellte Kameraquellen können als Kartenebene eingebunden werden.

06 // AI

Voice / AI

Optionaler OpenAI-Realtime-Zugang für sprachgesteuerte Kartenfunktionen und Navigation.
