# Contributing / Mitwirken

<p align="center"><a href="#deutsch"><strong>Deutsch</strong></a> · <a href="#english"><strong>English</strong></a></p>

## Deutsch

Beiträge sind willkommen. Besonders hilfreich sind reale DF100M-GATT-Ausgaben, BLE-Paketmitschnitte, Firmware-Versionen, reproduzierbare Speed-/Status-Payloads und Raspberry-Pi-Testberichte.

Bitte bei Protokollbeiträgen immer angeben:

- Gerät und Firmware
- App-Version
- Characteristic UUID
- Payload als HEX
- erwartete Wirkung
- beobachtete Wirkung

Dokumentationsänderungen werden nach Möglichkeit parallel unter `docs/de/` und `docs/en/` gepflegt. Statusangaben müssen zwischen `implemented`, `experimental`, `baseline/design` und `planned` unterscheiden.

Keine Passwörter, Tokens, privaten API-Schlüssel oder persönlichen Geräte-Accounts committen.

## English

Contributions are welcome. Real DF100M GATT output, BLE packet captures, firmware versions, reproducible speed/status payloads, and Raspberry Pi test reports are especially valuable.

Protocol contributions should always include:

- device and firmware
- app version
- characteristic UUID
- payload in HEX
- expected effect
- observed effect

Whenever practical, documentation changes should be maintained in parallel under `docs/de/` and `docs/en/`. Status statements must distinguish between `implemented`, `experimental`, `baseline/design`, and `planned`.

Never commit passwords, tokens, private API keys, or personal device accounts.
