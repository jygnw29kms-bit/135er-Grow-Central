# Contributing

Beiträge sind willkommen.

Besonders hilfreich:

- reale DF100M-GATT-Ausgaben
- BLE-Paketmitschnitte
- Firmware-Versionen
- reproduzierbare Speed-/Status-Payloads
- Raspberry-Pi-Testberichte

Bitte bei Protokollbeiträgen immer kennzeichnen:

- Gerät
- Firmware
- App-Version
- Characteristic UUID
- Payload HEX
- erwartete Wirkung
- beobachtete Wirkung

Keine Passwörter, Tokens, privaten API-Schlüssel oder persönlichen Geräte-Accounts committen.
