# Mobile v0.1 release gate

Mobile v0.1 remains a test candidate until all of the following are true:

- Build 71 source checkpoint secured;
- Build 72 image workflow successful;
- Android APK workflow successful and real-device tests passed;
- iOS unsigned IPA workflow successful, locally signed, sideloaded and real-device tests passed;
- installation links and QR codes point to actual published artifacts;
- public website and README are updated only after those gates pass.
