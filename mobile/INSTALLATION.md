# Installation – Mobile v0.1

## Android

1. GitHub-Actions-Artefakt `GrowCentral-Mobile-v0.1-Android-debug` laden.
2. APK auf das Android-Gerät übertragen.
3. Installation aus der verwendeten Quelle erlauben und APK installieren.
4. Beim ersten Start `http://135er-Grow-Central.local/` verwenden; beim First Boot `http://10.42.0.1/`.

## iPhone / iOS

1. GitHub-Actions-Artefakt `GrowCentral-Mobile-v0.1-iOS-unsigned` laden.
2. Die unsigned IPA mit einer zum Zielgerät passenden Apple-ID/Provisionierung signieren.
3. Per geeignetem Sideload-Werkzeug vom PC/Mac auf das iPhone installieren.
4. Beim ersten Start dieselbe lokale Grow-Central-Adresse wie unter Android verwenden.

## Hinweis

Mobile v0.1 ist vor Abschluss der Realgerätetests ein Testbuild und kein freigegebener Produktionsrelease.
