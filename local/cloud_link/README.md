# Local Cloud Link

Der Cloud Link läuft **auf dem Raspberry Pi** und baut ausschließlich ausgehende HTTPS-Verbindungen zum VServer auf.

Der Pi bleibt Master:
- lokale Automationen laufen auch ohne Internet
- Remote-Befehle sind standardmäßig deaktiviert
- Cloud-Ausfall beeinflusst den lokalen Betrieb nicht
