# Mars Hydro iFresh / DF100 / DF100M

## Authoritative classification

Within this project, **DF100** means the **Mars Hydro iFresh series using iConnect**. The target architecture groups it with the **Mars Hydro FC3000 model year 2024 with USB port and iConnect support** as one Mars Hydro/iConnect device family.

The existing DF100M / `MZ_MZF002` focus remains technically useful, but only as an experimental diagnostics, reverse-engineering, and fallback path.

## Existing BLE diagnostics path

- BLE discovery
- connect/disconnect
- GATT inspection
- experimental notification capture
- guarded raw/speed tests, disabled by default

Candidate UUIDs and strings are reverse-engineering observations, not official vendor protocol documentation.

Keep:

```text
DF100M_ALLOW_WRITES=false
DF100M_ALLOW_RAW_WRITES=false
```

until a real device path has been observed, replayed, and repeatedly validated.

The Raspberry Pi remains the local master. ESP32 is not part of the target architecture.

See `docs/MARS_HYDRO_ICONNECT.md` for the authoritative hardware profile.
