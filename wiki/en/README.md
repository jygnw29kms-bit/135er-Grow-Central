# 135er-Grow Central – Wiki Overview

135er-Grow Central is a Debian/Ubuntu-based local-first control and monitoring platform. The Raspberry Pi remains the local master; a Linux VPS is an optional extension.

Core areas include users/RBAC, devices, sensors, history, schedules, automations, alerts, audit logging, backups, cloud sync, DF100M BLE integration and a responsive web UI.

## Current sensor status · 14 October 2026

Firmware 0.4.1: USB onboarding, MQTT over TLS and soil history display confirmed on one patched Pi 4 installation. The new candidate Build 375 bundles firmware 0.4.1 and the fixes. Historical original image 369 still bundles firmware 0.4.0. Calibration, long-running stability and other hardware classes remain unverified.
