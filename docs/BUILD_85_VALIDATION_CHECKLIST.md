# Build 85 Folgeprüfung

- [ ] Raspberry Pi bootet bis zur Konsole/GUI ohne Regression.
- [ ] 135er-Grow-Central Markenzeichen ist beim Boot sichtbar.
- [ ] Bootstatus/Systemmeldungen bleiben lesbar.
- [ ] Setup-AP erscheint wie bei Build 85 und PMF bleibt aktiviert.
- [ ] GUI unter 10.42.0.1 bzw. lokalem Host erreichbar.
- [ ] Logitech C920 wird als UVC/V4L2-Kamera erkannt.
- [ ] Kamera-Menü zeigt die von der Kamera angebotenen Regler.
- [ ] Auflösungsauswahl bietet maximal 1280×720.
- [ ] Direkte 1920×1080-Anfrage wird serverseitig abgewiesen.
- [ ] Status-LED-Regler erscheint nur, wenn die Kamera/der Kernel ihn tatsächlich anbietet.
- [ ] Snapshot funktioniert in 640×480 und 1280×720, sofern von der Kamera angeboten.
- [ ] MJPEG-Livebild funktioniert bei maximal 720p.
- [ ] Elecrow 7-Zoll-Display wird bei 1024×600 bzw. 800×480 erkannt.
- [ ] Ohne Elecrow/7-Zoll-Profil bleibt HDMI auf EDID/KMS-Automatik.
- [ ] Headless-Boot bleibt möglich.
